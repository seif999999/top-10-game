# Sound Assets

This folder contains audio files for the app's sound effects and background music.

## Required Files

Add the following audio files to this folder:

| File | Purpose | Recommended Duration |
|------|---------|---------------------|
| `click.mp3` | Button click sound | 50-100ms |
| `success.mp3` | Correct answer, reward claimed | 500ms-1s |
| `error.mp3` | Wrong answer, error state | 300-500ms |
| `game-start.mp3` | Game begins | 1-2s |
| `game-end.mp3` | Game over | 1-2s |
| `background-music.mp3` | Looping background track | Any (will loop) |

## Free Sound Sources

- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sound effects
- [Freesound](https://freesound.org) - Community sound library
- [Zapsplat](https://www.zapsplat.com) - Free sound effects

## Notes

- Keep files small for fast loading (under 100KB for SFX)
- Use MP3 format for best compatibility
- Background music should be designed to loop seamlessly
