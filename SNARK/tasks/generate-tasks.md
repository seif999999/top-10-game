# Task Generation Template

## Instructions
Use this template to generate development tasks from a Product Requirements Document (PRD). Each task should be:
- Specific and actionable
- Include acceptance criteria
- Have clear dependencies
- Be sized appropriately (1-8 hours typically)

## Usage
1. Read the PRD thoroughly
2. Break down each requirement into specific, actionable tasks
3. Use the template above for each task
4. Ensure tasks are properly sequenced based on dependencies
5. Estimate time for each task realistically
